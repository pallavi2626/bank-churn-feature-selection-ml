   <h2>Project Description</h2>
<p>
    This project focuses on feature selection techniques in Machine Learning using the Bank Customer Churn dataset. The main objective is to identify the most relevant features that contribute to customer churn and improve the performance of machine learning models.
  </p>
  <h2>Objectives</h2>
  <ul>
    <li>To understand the Bank Customer Churn dataset.</li>
    <li>To perform data preprocessing and exploratory data analysis.</li>
    <li>To identify important features using feature selection techniques.</li>
    <li>To reduce irrelevant or redundant features.</li>
    <li>To improve the efficiency and performance of machine learning models.</li>
  </ul>
